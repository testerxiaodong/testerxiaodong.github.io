一、入门：类型、变量和表达式（1—12）

1. Python 是动态类型还是弱类型？“解释型”意味着不编译吗？

热度：★★★★★｜难度：入门

参考答案： Python 是动态类型语言，变量名在运行时绑定对象，对象本身具有类型；一般也称为强类型语言，不会无条件把不兼容的对象自动转换成可运算类型。例如字符串和整数直接相加会抛出 TypeError。

“动态”与“弱类型”是不同维度。变量名可以先绑定整数、再绑定字符串，不代表整数对象自身变成字符串。

追问： CPython 通常先把源码编译成代码对象和字节码，再由解释器执行。不能把“解释型”理解为完全没有编译步骤，也不能据此断言所有 Python 实现的执行方式完全相同。

2. Python 的变量与赋值是怎样工作的？函数参数是值传递还是引用传递？

热度：★★★★★｜难度：基础

参考答案： 赋值建立名称与对象的绑定，不会默认复制对象。函数调用时形参绑定到传入的对象，常称为对象共享或传对象引用；用“值传递/引用传递”二选一容易遗漏重绑定与修改对象的区别。

def update(items, number):
    items.append("new")   # 修改调用方也能看到的对象

3. 可变与不可变对象有什么区别？元组里能放列表吗？

热度：★★★★★｜难度：基础

参考答案： 列表、字典、集合通常可变；整数、字符串、元组等不可变。不可变指对象自身的结构或值不能原地修改，不代表它引用的所有对象都递归不可变。

元组可以引用列表，不能替换元组中的引用位置，但可以修改那个列表。这样的元组也不能用作字典键，因为它包含不可哈希成员。

易错点： 不可变、可哈希和线程安全不是同义词，要分别判断。

热度：★★★★★｜难度：基础

参考答案： is 比较对象身份，== 比较相等关系，后者可由类型自定义。判断单例 None 通常使用 is None；比较业务值使用 ==。

5. 哪些值是假？and、or 一定返回布尔值吗？

热度：★★★★★｜难度：基础

参考答案： None、False、数值零、空容器等通常为假。自定义对象可以通过 __bool__ 或 __len__ 定义真值。and、or 会短路，并返回操作数，不保证返回 bool。

6. /、//、% 有什么区别？负数整除如何计算？

热度：★★★★☆｜难度：基础

参考答案： / 是真除法；对于整数，// 向负无穷方向取整，而不是向零截断；整数余数遵循 a == (a // b) * b + a % b，除数不能为零。

7. 如何区分“没传参数”与“显式传了 None”？

热度：★★★★☆｜难度：基础

参考答案： 使用唯一哨兵对象，避免让一个值承担两种不同语义。这在配置更新、PATCH 接口和可选过滤条件中很常见。

def resolve(value=MISSING):
    if value is MISSING:
        return "use default"
    if value is None:
        return "explicitly clear"

10. 列表推导式与生成器表达式有什么区别？

热度：★★★★★｜难度：基础

参考答案： 列表推导式立即计算并保存结果，适合多次访问；生成器表达式按需产出，适合流式处理，但通常只能遍历一次。

squares = [x * x for x in range(4)]

assert squares == [0, 1, 4, 9]
assert sum(stream) == 14
assert list(stream) == []

生成器节省结果存储空间，不保证一定更快，也不是“完全不占内存”：它仍保存迭代状态及引用。不要用复杂嵌套推导式执行副作用；难以阅读时拆成普通循环。

11. str 与 bytes 的区别是什么？编码和解码方向是什么？

热度：★★★★★｜难度：基础

参考答案： str 表示 Unicode 文本，bytes 表示字节序列。encode 将文本编码为字节，decode 将字节按编码解释为文本。

1

text = "中文"
raw = text.encode("utf-8")
assert len(text) == 2
assert len(raw) == 6
assert raw.decode("utf-8") == text

文件、网络和数据库边界应明确编码，不应默认所有字节都是 UTF-8。errors="ignore" 可能悄悄丢数据，只能在明确接受损失时使用。文本字符数量也不总等于屏幕上可见的字符簇数量，emoji 和组合字符尤其需要注意。参见Unicode 官方指南。

12. 为什么 0.1 + 0.2 != 0.3？金额怎样计算？

热度：★★★★★｜难度：基础

参考答案： 常见二进制浮点数不能精确表示许多十进制小数，因此运算结果包含表示误差。科学计算可按业务容差比较；金额常使用最小货币单位整数或 Decimal，并明确精度和舍入规则。

1
2
3
4
5
6

from decimal import Decimal, ROUND_HALF_UP
import math

assert math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9)
amount = Decimal("2.675").quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
assert amount == Decimal("2.68")

从字符串构造 Decimal，避免先经过不精确的 float。Decimal 也受上下文精度、舍入和异常策略影响，并不意味着任意运算都自动符合财务规则。参见Decimal 文档。

61. Lock、RLock、Semaphore、Event、Condition 如何选择？

69. 常见死锁与事件循环阻塞是怎么产生的？

参考答案： 线程死锁常来自不一致的加锁顺序、持锁等待其他线程、或线程池任务等待同池内无法调度的任务。异步程序则常因在事件循环线程执行同步 I/O、长时间 CPU 循环或错误使用阻塞锁而停滞。

def two_sum(values, target):
    seen = {}
    for index, value in enumerate(values):
        previous = seen.get(target - value)
        if previous is not None:
            return previous, index
        seen[value] = index
    return None

# Python 3.11+；示例不访问外部接口
import asyncio

async def process_all(values):
    queue = asyncio.Queue(maxsize=6)
    stop = object()
    output = []
    worker_count = 3

    async def produce():
        for value in values:
            await queue.put(value)
        for _ in range(worker_count):
            await queue.put(stop)

    async def consume():
        while True:
            value = await queue.get()
            try:
                if value is stop:
                    return
                await asyncio.sleep(0)
                output.append(value * 2)
            finally:
                queue.task_done()

    async with asyncio.TaskGroup() as group:
        group.create_task(produce())
        for _ in range(worker_count):
            group.create_task(consume())
    return output

assert sorted(asyncio.run(process_all(range(10)))) == list(range(0, 20, 2))

边界： 示例 output 仍是内存列表，大规模时要替换为有界批量写出。本例采用任务失败即取消整组的策略；若要部分成功，需逐条记录可重试与永久失败，并处理取消和退出，不能简单吞异常。输出顺序也不保证与输入相同，可附序号后有界重排。

import time
from unittest.mock import Mock


def retry(operation, *, attempts=3, sleep=time.sleep):
    if attempts < 1:
        raise ValueError("attempts must be positive")
    for index in range(attempts):
        try:
            return operation()
        except TimeoutError:
            if index == attempts - 1:
                raise
            sleep(min(0.1 * (2 ** index), 1.0))

operation = Mock(side_effect=[TimeoutError("temporary"), "ok"])
assert retry(operation, sleep=lambda _: None) == "ok"
assert operation.call_count == 2

84. 服务运行几天后内存越来越高，怎样排查？

热度：★★★★★｜难度：故障排查

参考答案： 先确认增长是持续、台阶还是正常缓存预热，区分 RSS 与 Python 可追踪分配。固定工作负载比较内存快照，定位对象类型和引用链，检查无界缓存、全局列表、回调闭包、未结束任务和批量结果。

若 tracemalloc 增长不明显而 RSS 持续增长，检查原生扩展、内存映射和分配器保留，不应直接认定“GC 失效”。观察 GC 统计可以辅助，但反复 gc.collect() 通常不能修复仍被引用的数据。

项目闭环： 加入缓存容量和任务数量指标，建立可复现的长时间或批次压力测试。修复后验证增长曲线、吞吐和延迟，而不是只看服务重启后内存下降。

85. 接口平均响应突然变慢，如何判断该优化 Python 代码还是数据库？

热度：★★★★★｜难度：故障排查

参考答案： 先看分位延迟和分阶段耗时：入口排队、认证、业务 CPU、数据库、远程依赖和序列化。平均值可能掩盖少量长尾请求，应比较相同请求类型与负载。

CPU 高时检查算法、重复计算和序列化热点；CPU 不高但延迟高时，重点看连接池等待、慢查询、锁竞争、外部超时与事件循环阻塞。数据库问题还需检查查询计划、索引和 N+1 请求，而不只是换更快的 JSON 库。

取舍： 缓存要定义一致性和失效策略，扩线程要考虑下游容量，异步改造要确认依赖链是否真的非阻塞。每项优化都用相同负载验证收益和副作用。

88. 定时任务跨时区运行，怎样避免漏执行和重复执行？

热度：★★★★☆｜难度：项目设计

参考答案： 先区分“每隔固定时长”与“当地时间每天某时”两个需求，明确业务时区和夏令时策略。持久化时间点通常使用 UTC，但业务日期应按目标时区计算。

为每个计划窗口建立稳定任务键，通过持久化状态、唯一约束或适当锁控制重复执行；完成后记录输入范围与结果。进程重启、调度延迟和上次未完成时，明确补跑、跳过或合并策略。

易错点： 仅在进程内用布尔变量标记已执行，无法应对多副本和重启。每天 sleep 24 小时也不等于“每天当地 9 点”；本地时间在夏令时切换时可能重复或不存在。处理必须符合业务定义。

89. 如何把一次性 Python 脚本改成可维护的后台任务或服务？

热度：★★★★☆｜难度：项目设计

参考答案： 抽离输入、核心处理和输出，消除导入副作用和隐式全局状态。增加结构化配置、有限超时、错误分类、幂等、指标和可关联日志，并按资源生命周期关闭连接与执行器。

90. 面试官让你讲一个 Python 项目，怎样体现真实能力？

热度：★★★★★｜难度：综合表达

参考答案： 按“业务问题 → 约束 → 方案 → 关键实现 → 验证证据 → 仍存在的限制”讲一个具体案例。不要只列“用了多线程、装饰器和 Redis”。

容易说错的话 更准确的表述
Python 是弱类型语言 动态类型不等于弱类型，对象有明确类型
变量就是装值的盒子，赋值会复制 名称绑定对象，赋值通常不复制
不可变对象内部什么都不能变 不可变容器仍可引用可变对象
元组都可以当字典键 元组所有成员都可哈希才行
dict/set 操作永远 O(1) 通常平均 O(1)，还要考虑最坏与哈希比较成本
is 比 == 快，所以都用 is 身份与相等是不同语义
默认列表每次调用都会重新创建 默认表达式通常在定义执行时求值
生成器完全不占内存 仍有状态和引用，消费方也可能积累结果
finally 一定不会改变返回结果 finally 中返回或抛错可能覆盖原结果
del 保证立刻把内存还给系统 先删除绑定，生命周期与分配器需另行判断
Python 有 GC 就不会内存泄漏 仍被引用的无界缓存、任务和容器不会自动消失
有 GIL 就不需要锁 业务复合操作仍需同步，且构建和版本不同
result 超时会停止线程执行 通常只停止等待，正在执行的工作仍可能继续
多进程一直默认 fork 默认方式与平台、版本有关
async 函数天然并行 需要调度与协作等待，也不自动跨 CPU 并行
Semaphore 能限制所有内存占用 若预创建大量任务，任务自身仍会占内存
类型注解会验证 JSON 注解不等于运行时输入校验
replace(tzinfo=...) 就是时区转换 实际转换应明确使用 astimezone 等机制
deepcopy 能复制任何资源并完成隔离 资源对象和业务所有权需单独设计
自由线程让所有程序自动更快 兼容性、同步、争用和工作负载都影响结果
